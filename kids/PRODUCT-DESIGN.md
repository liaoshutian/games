# 糖果星球：产品与体验设计手册

## 产品定位

面向 3–6 岁儿童的原创 3D 探索游戏平台。孩子不需要阅读任务说明，也不需要理解复杂规则；主要通过触摸、拖拽、观察角色反应和听声音来理解世界。平台的目标是提供安全、温柔、可重复探索的游戏体验，而不是用倒计时、失败惩罚或付费压力驱动游玩。

## 体验原则

1. **先玩后懂**：进入世界后立即出现可互动的东西，不强迫看教程。
2. **动作就是语言**：角色通过眼神、耳朵、身体姿态、表情、音效表达开心、好奇、困惑、惊喜和不喜欢。
3. **尝试没有惩罚**：奇怪的组合产生有趣反馈，不能用羞辱或强烈负面声音惩罚孩子。
4. **一个角色，一整个宇宙**：星芽贯穿六个世界；小镇会展示孩子带回的花、蘑菇和贝壳。
5. **短回合、长探索**：每次互动几秒就有反馈，但孩子可以持续自由组合、发现隐藏内容。
6. **家长友好**：无广告、无账号、无外部聊天、进度保存在本地；家长设置通过长按进入。

## 核心循环

探索小镇 → 选择世界 → 自由互动或完成小小挑战 → 看到角色表演和声音反馈 → 获得星星/世界收藏 → 返回小镇观察变化 → 发现下一个玩法。

星星是轻量奖励，不影响孩子进入任何世界。所有世界默认开放，避免因年龄、识字能力或进度差异产生挫败。

## 六个世界

### 甜品王国
- 操作：点击或拖拽食材、选择底胚、搅拌、烘焙。
- 底胚：蛋糕、披萨、面包、汤。
- 食材：草莓、香蕉、蓝莓、巧克力、奶油、糖针、芝士、西兰花、小鱼、番茄、鸡蛋、蘑菇、蜂蜜、胡萝卜、棉花糖。
- 结果：配方影响外观、角色情绪和音效。可出现精美甜品、咸香料理、怪味料理和意想不到的组合。
- 表演：兔子靠近并吃掉喜欢的成品；不喜欢时兔子惊讶、动物顾客皱眉后退，之后换一位顾客，鼓励继续尝试。
- 长期变化：成功料理会留下一枚“甜品记忆”，并给小镇带回糖果色彩。

### 星光森林
- 操作：寻找漂浮星星、触碰蘑菇、呼唤伙伴、用灯笼照亮角落、收集发现。
- 惊喜：蘑菇会飞出蝴蝶；树洞会打开秘密星星；萤火虫在灯笼照亮后更显眼。
- 角色：小刺猬/森林伙伴回应呼唤、靠近星芽。

### 梦幻海洋
- 操作：戳泡泡、喂鱼、清理海藻、收集贝壳。
- 反馈：鱼会游动、摆尾和靠近；清理海藻后露出宝物；贝壳加入小镇收藏。
- 设计目标：以温和方式表达照顾海洋和观察生物。

### 四季花园
- 操作链：播种 → 浇水 → 阳光 → 开花 → 采收。
- 每盆花记住自己的成长阶段；过早使用工具会给出图标提示，而不是失败提示。
- 采收会让花朵绽放、蝴蝶出现，并让小镇花园逐渐变丰富。

### 星光衣橱
- 操作：切换六种造型、叠加配饰、转圈拍照。
- 角色动作：换装后转圈，配饰出现时做出开心回应。
- 设计目标：鼓励审美表达，不打分、不比较、不评判“最好看”。

### 奇想玩具城
- 操作：在场景中点按放置积木、斜坡、齿轮和桥，再启动滚珠机关。
- 反馈：齿轮转动、滚珠沿搭建路径移动，完成复杂作品后角色庆祝。
- 设计目标：用可观察的因果关系鼓励尝试和空间想象。

## 角色表演系统

角色包含待机呼吸、眨眼、耳朵/手臂动作，以及以下情绪动作：
- 开心：跳跃、挥手、转圈、脸颊泛红。
- 好奇：歪头、靠近、短促提示音。
- 试吃：靠近食物、张嘴咀嚼、食物缩小/消失。
- 不喜欢：皱眉、后退、低音效，然后出现新顾客。
- 惊喜：弹跳、星星粒子、清脆音效。

音效由 Web Audio API 生成，涵盖弹跳、魔法、泡泡、搅拌、烘焙、咀嚼、庆祝和困惑；游戏内可随时静音。浏览器策略可能要求首次触摸后才开始声音。

## iPad 与触控

- 游戏视图铺满浏览器可用视口，支持动态视口高度、安全区域和方向切换。
- 主要触控目标约 40–58 CSS px；底部工具栏允许横向滚动。
- 不依赖悬停、精细鼠标操作或键盘。
- 游戏界面以图标为主；文本仅用于家长区域和辅助技术标签。
- 支持减少动态效果偏好；不依赖高频闪烁或强烈屏幕震动。

## 本地收藏与隐私

- 星星、世界完成标记和收集资源仅写入浏览器 localStorage。
- 不要求登录，不采集姓名、生日、照片或定位。
- 家长设置通过长按打开，避免儿童轻易重置进度。
- PWA 可加入 iPad 主屏幕；Service Worker 缓存应用外壳，首次联网加载后可在一定范围内离线打开。Three.js 首次缓存失败时仍需要网络。

## 精品化验收标准

- 每个可点击对象都有可见反馈和合适的音效/动画。
- 不出现无法恢复的卡死；重开世界不会触发旧回合奖励。
- 横屏/竖屏布局不遮挡核心操作。
- 所有玩法在不读文字的情况下都能通过图标和即时反馈被发现。
- 成功与失败都是故事的一部分；没有羞辱、倒计时压力或付费诱导。
- 通过静态语法、DOM 引用、构建与部署检查；真实 iPad 设备仍需进行触控和音量验收。
