噗噜小世界 · 产品与交互设计

本设计先于新版代码实现。交付位置：仓库 kids/，通过 GitHub Pages 访问。首发四个完整原创 3D 世界，面向 3–6 岁，重点考虑不识字的 4 岁儿童。App Store 精选是设计方向，不代表网页上线即完成商店发行。

平台与原创角色

噗噜：奶油色圆头、薄荷色云朵耳、短肢、橙色星形挂件。统一软陶质感、暖光和简洁场景；不使用现成 IP 的角色、名字、服装或模型。噗噜在厨房、花园、车间、海湾四个世界陪伴孩子。兔子、猫、熊及海洋伙伴都有与当前事件相对应的动作。

首页→点世界卡片或 3D 小岛→直接进入全屏游戏→手势演示下一操作→点工具和实物→看物体变化→得到作品贴纸→选择再玩或回家。所有世界开放，无账号、广告、充值、排行或倒计时压力。作品册与设置只存在本机，不上传个人信息。

全局交互合同

主要工具与按钮至少 64×64 CSS px，间距至少 10px；3D 小目标使用扩大命中区。按钮用具象图标，文字只作辅助，不能靠文字才能通关。当前步骤显示图标轨道；等待约 7 秒出现手指，指向实际目标。帮助重复当前阶段提示，可静音，关闭声音后仍有手势与动画。点选工具显示边框和勾；点实物必须有物体、表情或场景变化。误操作显示所需图标、高亮正确工具，不扣分。

单游戏隐藏首页导航，占满安全区域与动态视口。iPad mini 1133×744、1024×768、744×1133、768×1024 都检查横竖屏。支持的浏览器直接触摸后请求系统全屏；iPad Safari 的系统栏由系统控制，主屏幕安装支持独立窗口，不能宣称强制隐藏所有系统栏。

动画期间锁定会破坏本轮的动作，回家、帮助、静音仍有效；返回或重玩取消旧回调。后台暂停动画和音频；恢复不跳过整个回合。拖拽均有点按替代。减少动态效果选项降低粒子和弹跳，不使用闪烁或屏幕震动。家长入口按住两秒，清空作品须再次确认。

1. 烘焙厨房

1. 兔子挥手，桌上放着大碗。选蛋糕、披萨或汤，改变底型清空碗。两页食材共十种：面粉、鸡蛋、牛奶、草莓、可可、胡萝卜、芝士、小鱼、蜂蜜、蘑菇；允许重复组合，最多八份。点食材实际飞入碗，图示示例配方为面粉+蛋+奶，放入的示例食材打勾；示例不限制自由选择。

2. 点勺子三次或在碗中划动搅拌。勺子绕碗转、颗粒融合、面糊随原料变色。不充分搅拌也能继续，结果会结块。工具显示三个填充点。

3. 三档火候：短、适中、长，分别用沙漏与一/二/三格图示。炉门和暖光、蒸汽、膨胀动画约三秒。蛋糕需面粉+蛋+奶，披萨需面粉+芝士，汤需奶/蘑菇/胡萝卜之一。短时湿软、长时焦黑、缺关键材料塌陷、搅拌不足结块；充分搅拌且中档才稳定成型。结果由真实 3D 形状、颜色、颗粒、烟雾表达。

4. 用草莓、奶油、可可装饰，最多六份。顾客偏好气泡：兔子胡萝卜/草莓，猫小鱼/芝士，熊蜂蜜/可可。点顾客或换客按钮切换；口味与物理制作质量分开判断。

5. 点端盘，成品移到顾客面前。合格且喜欢时走近、张嘴、分三口吃掉实物，配咀嚼音与开心跳跃。不喜欢时闻味、摇头后退；熊面对焦黑食物扇风轻咳。保留不喜欢的食物，不强迫进食，不羞辱孩子。失败也保存发现贴纸。

6. 结果有当前成品图示，两个大按钮为再做一份、回家。下一份可换配方、火候、装饰和顾客，不以装饰替代玩法。

必须检查：面粉蛋奶充分搅拌中档→蓬松蛋糕；同配方长档→焦黑；缺面粉→塌陷；未搅拌→结块；猫与兔子对甜食不同反应；喜欢时三口吃掉而非只显示提示。

2. 四季花园

三块独立地块。选草莓、胡萝卜或花种→点空地，种子破土。水壶点地两次分别长叶；太阳让植物成长。过量浇水会积水、叶子下垂，太阳先蒸发积水，之后仍可继续成长。胡萝卜可能出现小虫，用软刷赶走；花朵成熟后需蜜蜂授粉。地块上方始终显示当前所需工具，误点后指示正确工具。

每种植物有不同的真实立体结果：草莓株、萝卜、花。点篮子再点成熟植物，实际收获飞入篮子；同一株只能收获一次。三次采收完成一轮，展示三枚收获贴纸。各地块阶段独立；切换工具或地块不重置其他植物。可重复选择同一种，也可尝试三种。重玩恢复三块空地，长期作品保留。

3. 奇想车间

车体：木箱/船身/轻车身；轮子：小轮/大轮/桨轮；车顶：旗子/风帆/螺旋桨。点分类，再点零件，安装在对应部位并改变真实模型。可点车查看旋转。选择草地、石坡、水道，场景地形同步变化。

点发车，车轮、桨轮、螺旋桨实际转动。草地所有组合可通行；石坡需大轮或螺旋桨；水道需船身或桨轮。风帆让水道更快，螺旋桨让车跨坡时抬起。不适配时在障碍前停住或轻轻浮动，显示所缺部件，不发生惊吓事故。扳手按钮回到装配，保留零件及路线，换一个部件即可验证因果。

到终点旗后噗噜庆祝，收藏车辆和路线贴纸；可改装原车挑战另一地形或重造。不能无论怎么搭都播同一个成功动画。

4. 蔚蓝海湾

小鱼、海龟、小海豹三位伙伴，点一个查看需要，支持随时切换并保留本轮步骤。

- 小鱼：网兜捞两片塑料垃圾，任何顺序均可；不是拔除健康海藻。之后鱼粮喂两口，食物进入嘴、鱼张嘴摆尾。

- 海龟：小刷子清理三处背部污渍，任意顺序；把两段珊瑚修回对应轮廓，点零件+点轮廓与拖动都可。两段可任意先后修复，修好的保持在场景里。

- 海豹：示范三个音符泡泡的顺序，声音和发光共同表达。孩子重复，错误不惩罚而重新演示。成功后击掌，海豹翻滚并回应。

每位完成后留下贝壳，点贝壳收藏并选择下一位；三位全部完成得到海湾贴纸、可重玩或回家。只呈现当前步骤有效物体，所有按钮和小目标均须可点、可恢复。

动画、音效与技术

噗噜待机呼吸、眨眼、挥手、歪头、开心跳跃；顾客包括闻味、摇头、吃、扇风。倒料/搅拌/烤箱/水滴/成长/车辆/泡泡/咀嚼/庆祝各有音效。浏览器首次触摸才开启音频；本地语音为辅助，不能成为唯一引导。

Three.js 与程序、图标同源存放，无外部 CDN。Service Worker 仅缓存 kids/，首次完整加载后测试断网重开。WebGL 不可用显示重试界面；损坏或禁用本地存储仍可玩。作品只存枚举和图标，不存照片、姓名、定位。所有世界默认开放。

验收门槛

从不识字四岁儿童角度检查：找得到入口，第一次触摸有变化，知道下一步，误点能恢复，完成后能再玩或回家。以实际操作和实物结果验收，不能只在文字里声称丰富。

自动化须覆盖四条完整流程、烘焙五种质量与口味分支、花园补救、车辆失败后改装、海湾三条任务、重复点击防重奖、退出取消、四组 iPad 视口、工具及 3D 目标≥64px、静音/收藏保存、离线重开、目录所有入口 HTTP 200、无运行异常。真实 iPad Safari、音量与儿童独立操作观察须明确标记实际状态，自动模拟不能冒充真机或儿童研究。
