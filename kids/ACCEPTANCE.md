## 复验方法

无需构建。仓库根目录运行 `python3 -m http.server 4173`，访问 `http://localhost:4173/kids/`。

规则测试：`cd kids && npm test`。浏览器测试：在 kids 目录执行 `npm install && npx playwright install chromium`，启动前述静态服务器后执行 `npm run test:browser`。环境变量 `BASE_URL` 可改测试地址，`CHROMIUM_PATH` 可指定系统浏览器，`QA_REPORT` 可改报告位置。

## 发行边界

交付为 GitHub Pages 网页平台，所有代码和运行素材同源，无 CDN、无广告和账号。作品仅存在当前浏览器。支持添加到主屏幕；Safari 系统栏是否隐藏取决于浏览器支持。实际 iPad/iPad mini Safari 触感与音量、四岁儿童独立操作观察仍需真机和用户测试。网页上线不等同于 App Store 发行，也不代表获得精选资格。
